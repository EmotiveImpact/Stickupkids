# Game sound

Made with Runway's sound effects tool (October 2026), prompts in the
thread "Add sound to the game". Raw files are in the project folder at
`audio/sfx-runway/`; `art/audio/prepare.sh` turns them into these.

- `amb-*`, `tension-drone`: looping beds, all at -26 LUFS.
- Everything else: one-shots, mono, peaked at -1 dB. The game pans them.

Music (Suno) and voices (Fish Audio) are still to come.
